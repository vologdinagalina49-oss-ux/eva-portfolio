ПОРТФОЛИО ЕВЫ — ПОЛНОЭКРАННАЯ ПРЕЗЕНТАЦИЯ

Откройте index.html в браузере. Это одна длинная страница из 11 полноэкранных слайдов. Листайте колесом мыши, клавишами вверх/вниз или свайпом. Стрелки у каждой работы переключают фотографии. Кнопка ОПИСАНИЕ открывает полный авторский текст. Нажатие на картину увеличивает её.

Фотографии взяты из доступных файлов проекта и ранее загруженных изображений. Если какая-либо фотография сопоставлена не с той работой, напишите название картины и имя файла — заменю без генерации изображений.
